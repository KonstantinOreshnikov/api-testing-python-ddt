# API Testing with Python and DDT

Educational project focused on data-driven API testing in Python.

## Scope

- API test scenarios
- Data-driven testing (DDT)
- Reusable test inputs
- Basic automated validation

## Status

Completed learning project. The repository remains available as part of my Python and QA practice portfolio.

## Note

This project is educational and is not intended for production use.

## Practical learning guide / Практическое руководство

[**API Testing and DDT practice**](docs/api-testing-practice.md) explains HTTP contract checks, data-driven cases, response validation, negative testing and safe synthetic fixtures.

API checks become one part of a wider [Quality Engineering route](https://github.com/KonstantinOreshnikov/web-testing-page-object). A fictional reporting API can be tested for schema, duplicate submission and consistent period filters.

**Historical code notice:** legacy training URLs and configurations are preserved unchanged. Do not reuse them as credentials or as a verified live test endpoint. The new guide does not connect to those services.
